Section 02 of 07

Fixed-parameter tractability

Theory notes

Parameterized problems and input size

A parameterized decision problem is a language Q⊆Σ*×ℕ. An instance is a pair (x,k), where x encodes the ordinary input and k is the parameter. For this size convention, write N=|x|+k, which treats the parameter as if it were written in unary.

For Vertex Cover, x encodes G, the parameter is the cover budget k, and we write n=|V(G)| and m=|E(G)|.

Fixed-parameter tractability

A problem Q is in FPT if one uniform deterministic algorithm decides every instance (x,k) in time

FPT bound: f(k)·Nc, for a computable function f and constant c independent of k.

The function f(k) may grow quickly; the polynomial exponent may not depend on k. For example, 2kN3 and k!N2 are FPT. A polynomial-time bound such as N5 is FPT with f(k)=1.

XP

XP is the class of parameterized problems solvable in slice-wise polynomial time: for each fixed parameter value, the running time is polynomial in the input size, but the polynomial degree may depend on that value. Formally, an XP algorithm runs in time f(k)·Ng(k), where f and g are computable. Trying every set of at most k vertices gives an XP algorithm for Vertex Cover, with running time on the order of Nk. Every FPT problem is in XP; the definitions do not establish that this inclusion is strict.

FPT many-one reductions

An FPT many-one reduction from Q to Q′ maps (x,k) to (x′,k′) and satisfies:

  • it runs in time at most f(k)(|x|+k)c;
  • (x,k)∈Q exactly when (x′,k′)∈Q′;
  • k′≤g(k) for a computable function g.

The time bound also bounds the output length. Since k′ is bounded by a function of k, there is a computable h with |x′|+k′≤h(k)(|x|+k)c. FPT reductions preserve FPT: if Q reduces to Q′ and Q′ has an FPT algorithm, composing the reduction and algorithm gives an FPT algorithm for Q. This definition gives context for parameterized hardness; the Vertex Cover algorithms below do not require a hardness reduction.

Parameterized coloring: a fixed-slice obstruction

In parameterized k-Coloring, k is the number of available colors. We know that 3-Coloring is NP-complete. For any fixed k>3, reduce 3-Coloring to k-Coloring by adding a clique of k−3 new vertices adjacent to every original vertex. Those new vertices use k−3 distinct colors, leaving at most three colors for the original graph. Thus each fixed slice with k≥3 is NP-hard; membership in NP is standard and assumed. If parameterized k-Coloring had an FPT or XP algorithm, fixing k=3 would give a polynomial-time algorithm for 3-Coloring. Hence, unless P=NP, it is neither FPT nor XP. NP-hardness at a fixed parameter value is called para-NP-hardness.

Side note: W[1]. The parameterized problem k-Clique is W[1]-complete under FPT reductions. Reducing k-Clique to a problem proves that problem W[1]-hard. The standard conjecture is FPT≠W[1], so W[1]-hardness is evidence against FPT, not an unconditional impossibility result. We omit the circuit-based definition of the W-hierarchy.

This complements the coloring example: its fixed-slice obstruction is conditional only on P=NP, while W[1]-hardness is a separate standard source of evidence against FPT.

Theorem 2.5: Vertex Cover is FPT

Vertex Cover parameterized by the cover budget k can be solved in O(2k(n+m)) time.

The next section proves this theorem with a branching algorithm and a correctness and runtime analysis. FPT does not automatically mean fast on every input: the function of k may be large, but for fixed small k, growing the graph contributes only a fixed polynomial factor.
