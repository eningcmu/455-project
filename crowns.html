Section 05 of 07

Matchings and crown reductions

Theory notes

Matchings and lower bounds

A matching is a set of edges with no shared endpoints. Every matching edge requires at least one endpoint in any vertex cover; disjointness means a matching of size r proves that every cover has size at least r. Thus if r>k, the instance is a no-instance.

A matching is maximal if no additional edge can be added, and maximum if it has largest possible size. A maximal matching is easy to find greedily, but it need not be maximum.

Alternating and augmenting paths

An alternating path alternates between edges outside and inside a matching. If it begins and ends at unmatched vertices, it is an augmenting path: switching the matched status of its edges increases the matching size by one. A maximum matching has no augmenting path. Alternating reachability from unmatched vertices is used to construct a crown.

Crown decomposition

A crown decomposition partitions V(G) into C,H,R satisfying:

  • C≠∅ and C is independent;
  • there are no edges between C and R, so H separates C from R;
  • there is a matching between C and H that saturates H.

The matching condition gives H⊆N(C); separation gives N(C)⊆H, so H=N(C). The matching also shows that at least |H| cover vertices are needed for its matched edges.

Crown reduction

Theorem. If (C,H,R) is a crown, then (G−(C∪H),k−|H|) is a yes-instance of Vertex Cover exactly when (G,k) is.

Proof. Let X be a vertex cover. For each matched pair (h,c), if h∉X, then c∈X; replace c by h. The matched vertices in C are distinct, so this does not increase the cover size. Adding vertices cannot uncover edges, and after these replacements X contains all of H. Since C is independent and has no neighbors in R, H covers every edge incident to C∪H. Removing C∪H leaves a cover using at most k−|H| vertices.

Conversely, add H to any cover of G−(C∪H) of size at most k−|H|. The set H covers every removed edge, giving a cover of G of size at most k. ∎
