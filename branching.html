A branching algorithm for Vertex Cover

Theory notes

Proof of Theorem 2.5: the branching algorithm

Given a graph G and a budget k, the algorithm decides whether at most k vertices cover every edge.

If an edge uv remains, every vertex cover contains u or v. Branch on these two exhaustive choices, spending one unit of budget in each branch.

VertexCover(G, k):
    if k < 0: return NO
    if E(G) is empty: return YES
    if k == 0: return NO
    choose an edge uv
    if VertexCover(G - u, k - 1) = YES:
        record u and return YES
    if VertexCover(G - v, k - 1) = YES:
        record v and return YES
    return NO

Here G−u means removing u and all edges of u. Recording the selected vertices lets the algorithm return a cover as well as a yes/no answer.

Correctness

Theorem. The algorithm returns YES exactly when G has a vertex cover of size at most k.

Proof. Induct on the nonnegative budget k; negative budgets are rejected immediately. If E(G)=∅, the empty set is a cover. If an edge remains and k=0, no cover of size zero exists.

Otherwise choose an edge uv. Every cover contains u or v. A cover containing u yields a cover of G−u of size at most k−1 after removing u; conversely, adding u to any cover of G−u covers all edges of G. The same holds for v. Hence the original instance is a yes-instance exactly when one recursive branch is, and the induction hypothesis applies to both branches. ∎

Running time

For a graph with n vertices and m edges, let T(k;n,m) bound the time on instances with budget at most k and graph size at most n,m. Each call makes at most two calls with budget k−1; selecting an edge and forming reduced graphs takes O(n+m) time:

T(k;n,m)≤2T(k−1;n,m)+O(n+m), with T(0;n,m)=O(n+m).

Therefore T(k;n,m)=O(2k(n+m)). Equivalently, the search tree has depth at most k, fewer than 2k+1 nodes, and O(n+m) work per node. This proves Theorem 2.5 and shows Vertex Cover is FPT parameterized by k. This is a worst-case bound; many branches stop early when no edges remain or when the remaining budget reaches zero while an edge is still present.
