Lecture 1 · Section 03 of 08

A branching algorithm for Vertex Cover

25 minutesPlanned content

What this page will cover

This section will present the algorithm that chooses an uncovered edge and branches on which endpoint to include. It will develop pseudocode and base cases, prove correctness by induction on the budget, and analyze the search tree to obtain the O(2k(n + m)) running time. A worked example will trace both a successful branch and a failed branch on a small graph.
